# Установка OJS 3.5 на ojs.genes.kz

Пошаговая инструкция развёртывания OJS 3.5.0-3 на хостинге hoster.kz (Plesk, LiteSpeed, PHP 8.4, MariaDB).

Доступ: FTP + панель Plesk (SSH отсутствует).

## Предварительные требования

- Субдомен `ojs.genes.kz` создан в Plesk
- SSL-сертификат активен для `ojs.genes.kz`
- PHP 8.4 включён для субдомена
- Доступ к Plesk File Manager и разделу Databases

## Пути на сервере

| Путь | Назначение |
|------|-----------|
| `/var/www/vhosts/genes.kz/ojs.genes.kz/httpdocs/` | Document root субдомена (сюда ставим OJS) |
| `/var/www/vhosts/genes.kz/ojs_files/` | Приватные файлы (рукописи, рецензии) — вне web root |

> Проверить точный document root: Plesk → Сайты и домены → ojs.genes.kz → Настройки PHP → значение `{DOCROOT}`.

## Шаг 1. Скачать OJS

Скачать архив с официального сайта:

**OJS 3.5.0-3:** https://pkp.sfu.ca/ojs/download/ojs-3.5.0-3.tar.gz

Сохранить файл на локальный компьютер.

## Шаг 2. Создать базу данных

1. Plesk → **Базы данных** → **Добавить базу данных**
2. Заполнить:
   - Имя базы данных: `ojs` (Plesk может добавить префикс)
   - Сервер: localhost
   - Сайт: ojs.genes.kz
3. Создать пользователя БД:
   - Имя пользователя: `ojs`
   - Пароль: сгенерировать надёжный пароль, **сохранить его**
4. Нажать **OK**
5. Открыть phpMyAdmin → выбрать созданную БД → **Operations** → установить collation: `utf8_general_ci` → **Go**

> **Важно:** использовать `utf8_general_ci`, а не `utf8mb4`. В OJS 3.5 есть баг — таблицы создаются как `utf8mb3` даже при указании `utf8mb4` ([pkp-lib#11563](https://github.com/pkp/pkp-lib/issues/11563)).

## Шаг 3. Создать директорию для файлов

В Plesk File Manager перейти в `/var/www/vhosts/genes.kz/` и создать папку `ojs_files`.

Полный путь: `/var/www/vhosts/genes.kz/ojs_files/`

> **Важно:** эта папка хранит рукописи и рецензии. Она ДОЛЖНА быть вне `httpdocs/`, чтобы файлы не были доступны напрямую через веб.

Установить права: **755**.

## Шаг 4. Загрузить OJS на сервер

**Рекомендуемый способ — через Plesk File Manager (быстро):**

1. Plesk → **Файлы** → перейти в `ojs.genes.kz/httpdocs/`
2. Загрузить файл `ojs-3.5.0-3.tar.gz`
3. Нажать на архив → **Извлечь файлы**
4. Появится папка `ojs-3.5.0-3/` — переместить всё её содержимое в корень `httpdocs/`
5. Удалить пустую папку `ojs-3.5.0-3/` и файл `.tar.gz`

> **Альтернатива — FTP:** подключиться FTP-клиентом, загрузить содержимое извлечённой папки в `ojs.genes.kz/httpdocs/`. Это медленно (тысячи файлов).

После загрузки в `httpdocs/` должны быть: `index.php`, `lib/`, `classes/`, `plugins/`, `config.TEMPLATE.inc.php` и т.д.

## Шаг 5. Настроить конфигурацию

1. Переименовать `config.TEMPLATE.inc.php` → `config.inc.php`
2. Открыть для редактирования (Plesk Code Editor или скачать через FTP)
3. Использовать `config/config.inc.php.example` из этого репозитория как справочник
4. Заполнить обязательные поля:

| Поле | Значение |
|------|----------|
| `base_url` | `https://ojs.genes.kz` |
| `time_zone` | `Asia/Almaty` |
| `database.username` | имя пользователя из Шага 2 |
| `database.password` | пароль из Шага 2 |
| `database.name` | имя БД из Шага 2 |
| `files_dir` | `/var/www/vhosts/genes.kz/ojs_files` |
| `salt` | случайная строка 32+ символов |
| `api_key_secret` | случайная строка 32+ символов |
| `restful_urls` | `On` |
| `force_ssl` | `On` |
| `job_runner` | `On` |
| `task_runner` | `On` |

5. Установить права на `config.inc.php`: **666** (временно, на время установки)

## Шаг 6. Скопировать .htaccess и .user.ini

Из папки `config/` этого репозитория скопировать в `ojs.genes.kz/httpdocs/`:
- `.htaccess` — правила перенаправления и безопасности
- `.user.ini` — настройки PHP для LiteSpeed FastCGI

## Шаг 7. Установить права на директории

В Plesk File Manager установить права **755** (рекурсивно) на:
- `ojs.genes.kz/httpdocs/cache/`
- `ojs.genes.kz/httpdocs/public/`

> LiteSpeed с Plesk использует FastCGI/suEXEC — PHP работает от имени владельца домена, поэтому 755 достаточно. Никогда не ставить 777.

## Шаг 8. Запустить веб-установщик

Открыть в браузере: **https://ojs.genes.kz/**

Установщик OJS проведёт через:
1. Выбор языка (русский, английский, казахский и др.)
2. Проверку системных требований
3. Подтверждение параметров БД
4. Подтверждение пути к файлам
5. Создание учётной записи администратора
6. Настройки OAI

После завершения установщик запишет `installed = On` в `config.inc.php`.

## Шаг 9. Загрузить кастомизации

Если в репозитории `genes-ojs` есть кастомные файлы в `custom/`:
1. Скопировать содержимое `custom/plugins/` → `ojs.genes.kz/httpdocs/plugins/`
2. Скопировать содержимое `custom/locale/` → `ojs.genes.kz/httpdocs/locale/`

Структура `custom/` зеркалит структуру OJS — файлы копируются поверх.

## Шаг 10. Действия после установки

### Защитить конфигурацию
Установить права на `config.inc.php`: **644** (или 444 для максимальной защиты).

### Настроить email
OJS admin → **Settings** → **Website** → **Setup** → **Emails**

Настроить SMTP-сервер для отправки уведомлений.

### Настроить cron-задачу в Plesk

1. Plesk → **Планировщик задач** (Scheduled Tasks)
2. **Добавить задачу**
3. Тип: **Fetch a URL**
4. URL: `https://ojs.genes.kz/`
5. Расписание: **каждые 15 минут**
6. Сохранить

Это обеспечивает обработку фоновых задач даже когда сайт не посещают.

### Создать журнал
OJS admin → **Hosted Journals** → **Create Journal**

Создать журнал Contig, настроить название, описание, контакты.

## Проверка

- [ ] https://ojs.genes.kz/ открывается, видна главная страница OJS
- [ ] Можно войти под учёткой администратора
- [ ] Создан журнал Contig
- [ ] Clean URLs работают (страницы без `index.php` в адресе)
- [ ] Можно подать тестовую рукопись
- [ ] Email-уведомления приходят
- [ ] В Plesk создана cron-задача

## Обновление OJS

При выходе новой версии OJS:
1. Сделать резервную копию БД и файлов через Plesk
2. Скачать новый tar.gz
3. Загрузить и распаковать поверх существующих файлов
4. Переложить кастомизации из `custom/` поверх
5. Запустить обновление БД (см. [docs/KNOWN_ISSUES.md](KNOWN_ISSUES.md) — раздел «Обновление OJS»)
6. Очистить кэш: удалить содержимое `cache/t_cache/` и `cache/t_compile/`
