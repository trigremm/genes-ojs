# genes-ojs

Развёртывание системы управления рукописями Open Journal Systems (OJS) для научного журнала **Contig** на платформе [genes.kz](https://genes.kz/Contig/index.html).

## Цель

Развернуть и настроить OJS для полного редакционного цикла журнала Contig: подача рукописей, рецензирование, публикация.
